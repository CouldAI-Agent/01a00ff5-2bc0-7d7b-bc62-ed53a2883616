# FPL Local League

A responsive web dashboard for a local Fantasy Premier League (FPL). Built with raw HTML, CSS, and JavaScript.

## Features
- **Live League Table**: Displays team rankings, manager names, gameweek points, and total points.
- **Manager of the Week**: A dynamic left sidebar component that automatically highlights the manager with the highest gameweek score.
- **Responsive Design**: Adapts beautifully to mobile, tablet, and desktop screens.

## Tech Stack
- HTML5
- CSS3 (Flexbox, CSS Variables, Animations)
- Vanilla JavaScript (ES6+)

## How to Run
Since this is a static web page, you can open it directly in your browser:
1. Double click on `index.html` to open it in Chrome, Safari, Firefox, or Edge.
2. Alternatively, run any local static file server, for example: `python3 -m http.server 8000` or `npx serve`.
